# MeetScribe

> **AI-assisted meeting action-item extractor transcript verification platform for multilingual, code-mixed Indian research interviews.**
> 
> An AI-powered transcript verification platform that improves the accuracy and reliability of research interviews. It supports multiple Indian languages, including Hindi, Telugu, Tamil, and mixed-language conversations. The system compares transcripts generated by different AI engines using RapidFuzz, identifies errors and mismatches, connects text to specific audio timestamps, and allows human reviewers to verify and track corrections before the transcripts are used for research and publication.

---

## 🎯 What MeetScribe Does

1. **Zero-Friction / Instant Access**:
   - No account creation, login, or registration is needed. Researchers can directly upload audio or video recordings or explore preloaded fieldwork interviews.

2. **Realistic 28-Minute Fieldwork Interview**:
   - Includes a preloaded **28:45-minute** qualitative research interview focused on rural digital payments and Direct Benefit Transfers (DBT), featuring conversations in **Telugu and English**.

3. **Intelligent Selective Flagging (80%+ Review Time Saved)**:
   - Rather than marking every transcript line for review, MeetScribe identifies only the segments containing potential errors or disagreements (e.g., **3 flagged lines out of 17 segments**). This helps researchers concentrate on uncertain or conflicting content and reduces unnecessary verification work.

4. **Dual-Engine Transcription Analysis**:
   - Compares and aligns transcripts generated independently by **Sarvam AI and Google Gemini Audio**. The system highlights important differences, including missing negations, incorrect numerical amounts, and inconsistencies caused by acoustic jitter.

5. **Two-Column Evidence-Connected Review Workspace**:
   - **Left Column**: Displays interactive transcript cards with pastel-colored speaker labels (`Researcher`, `Participant`), timestamp indicators, direct text editing, and one-click verification (`✓ Mark as Reviewed`).
   - **Right Sidebar**: Provides three inspection sections:
     - **Tools & Review**: Adjustable confidence threshold slider (25%–85%), real-time search and replace, and verification progress tracking.
     - **AI Insights**: Easy-to-understand research findings, summaries of transcription disagreements, and estimated time savings.
     - **Glossary**: A collection of research-specific terms and organization names with one-click terminology standardization.

6. **Built-In Audio and Video Playback**:
   - Features a sticky media player with **Play, Pause, and Stop** functions, adjustable playback speeds (**1.0x, 1.5x, and 2.0x**), and an accurate timeline slider (`00:00 / 28:45`) for navigating recordings.

7. **Research-Ready Transcript Verification Reports**:
   - Allows researchers to export detailed, audit-ready verification reports in **four file formats**: **Word (.docx), PDF (.pdf), Text (.txt), and JSON (.json)**. Each report includes timestamps, differences identified between transcription engines, and human verification signatures.

## 🚀 Quickstart: Running Locally

### Terminal 1: Backend API (FastAPI)
```powershell
cd backend
.\venv\Scripts\Activate.ps1
uvicorn app.main:app --reload --port 8000
```
*API documentation available at `http://127.0.0.1:8000/docs`.*

### Terminal 2: Frontend (Live Server)
```powershell
cd frontend
python -m http.server 5500
```
Open **`http://localhost:5500`** in your browser.

## ⚙️ Architecture & Tech Stack

| Component | Technology | Description |
|---|---|---|
| **Frontend** | HTML5, Modern CSS, Vanilla ES6 JavaScript | Zero-dependency, responsive two-column verification workspace and landing page |
| **Backend** | Python 3.11+, FastAPI, Uvicorn | Async REST API, audio streaming, export generators, and verification pipeline |
| **Transcription** | Sarvam AI & Google Gemini Audio | Dual independent speech-to-text engines with fallback handling |
| **Comparison** | RapidFuzz | Fuzzy string matching, token alignment, and selective discrepancy scoring |
| **Storage & Database** | SQLite + SQLAlchemy | Projects, recordings, segments, glossaries, insights, and audit records |
| **Export Formats** | `python-docx`, ReportLab | Formatted DOCX, PDF, TXT, and JSON report generation |
| **Hosting & CI/CD** | Vercel (Frontend) & Render (Backend) | Automatic deployment with dynamic backend URL discovery |
